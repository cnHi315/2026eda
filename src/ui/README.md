# UI 模块（B：任务 2、4）

| 文件 | 职责 |
| --- | --- |
| main_frame | 三栏窗口、文件/编辑/视图入口、六个等宽文字操作按钮、显隐开关和文件/子电路操作 |
| canvas_panel | 绘制、框选/整组编辑、连线、子电路放置、仿真上屏、撤销/重做 |
| component_palette | 通用树数据、整行灰阶绘制/命中、五类内置元件与自定义子电路 |
| property_panel | 元件/几何/引脚三张白色信息卡片、只读对齐文字、实时位置及长值换行/滚动 |
| ui_theme.h / ui_theme.cpp | 浅灰状态、连续圆角、文字按钮/带勾选菜单与应用内对话框 |
| subcircuit_library | 普通 Schematic JSON 片段的保存、扫描及兼容性检查 |

本周 UI 美化、第七周交付、Bug 状态、操作和测试见 [B-TODOLIST](../../docs/B-TODOLIST.md)。几何/交互约定见 [interfaces](../../docs/interfaces.md)。

model/io/components/simulation 接口由对应成员维护，UI 通过共享契约调用；不改变文件格式或后端签名。定向测试在 tests/，现有 CMake 自动收集新增 UI 源文件。

开关在系统双击时间/距离范围内按每一对已完成点击切换，避免GTK三连击分组造成漏切换。画布默认1单位精度，视图可选1/5/10/20、Alt临时自由移动、方向键1单位/Shift方向键10单位；20主网格和10辅助网格独立于坐标精度；拖动变化同步通知属性区，字段布局相同则复用控件更新文字。

选中效果直接作用于元件本体（浅蓝填充＋蓝描边），不再画外围选中/悬停框。实际拖动开始后清空选中，用已捕获的位置集合继续移动；`ActiveComponentCount()`为拖动中的属性检查提供数量，松开清空检查，Esc/捕获丢失还原位置和选中。选中专项见`tests/b_selection_test.cpp`，双缩放各21/21。
