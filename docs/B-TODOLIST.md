### 演练顺序与验收点

1. 从仓库根目录启动，确认三栏、工具栏和属性卡片；打开 `samples/demo.json`，核对 4 元件、3 导线、3 网络。
2. 连续双击两只开关，走完 AND 的四组输入，核对 LED；检查相邻元件条目切换。
3. 拖动元件查看实时坐标，检查取消选定、撤销/重做；切换吸附精度，微调后还原。
4. 多选封存子电路，刷新并加载放置，核对内部连线、整组移动与一次撤销。
5. 另存为并重新打开；导出同名 `.net` 和 `.pcb`，用原版 `pcb` 导入网表并生成飞线。
6. 核对工具栏/属性面板显隐、最小窗口与高分屏；记录总耗时、异常及恢复方式。

计时以实际执行结果回填；自动化耗时不代表现场人工讲解耗时。不得覆盖仓库样例，演练产物放在忽略的独立构建目录。

## 4. 当前操作说明

| 操作 | 用法与行为 |
| --- | --- |
| 放内置元件 | 元件库点类型→点击空白处，可连续放置；默认1单位精度，不受10单位参考网格限制；视图可切换1/5/10/20，Alt临时自由放置，Esc退出。 |

| 整组移动 / 删除 | 拖已选中的元件移动整组；Delete 删除整组及相连导线；各记一次历史。Esc 或失去捕获还原拖动。 |

| 子电路库 | 默认扫描启动工作目录的 `subcircuits/`；不存在时正常使用；保存后刷新，也可编辑→刷新子电路库。 |
| 放置子电路 | 点击“自定义子电路”下的条目→点击空白处；自动选中新块，可连续放；Esc 退出。 |
| 连线 | 引脚末端拖到目标引脚；非法连接在状态栏给出原因，Ctrl 点击引脚优先执行加选。 |
| 开关 / 属性 | 同一SWITCH在系统双击时间和距离内连续点两次切换，每一对各切换一次；单击只选中。单选显示元件/几何/引脚三张白色卡片，拖动实时更新位置；多选显示数量及组操作说明。 |
| 视图 | 文件/编辑/视图为顶部入口；视图勾选“工具栏”显示右侧六个等宽文字按钮，勾选“元件属性”显示右栏，取消勾选可隐藏；下方单选吸附1/5/10/20单位。 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y；整块放置、移动、删除各一次；保留现有开关挡位，恢复删除元件时恢复其挡位。 |
| 平移 | 中键 / 滚轮 / Shift+滚轮；当前不支持缩放。 |
| 文件 | Ctrl+N/O/S/E：新建/打开/保存/导出；另存为在文件菜单。保存 JSON 与导出独立；导出一次生成同名 gEDA `.net` 与 `.pcb`。 |

目前子电路只接受当前五类元件、兼容的引脚模板及零旋转；不兼容文件会跳过/拒绝，不静默丢弃连线。显式元件名称保留，默认 id 标签随新 id 更新。
