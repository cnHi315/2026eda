## 4. 当前操作说明

| 操作 | 用法与行为 |
| --- | --- |
| 放内置元件 | 元件库点类型→点击空白处，可连续放置；20 栅格吸附，Esc 退出。 |
| 单选 / 多选 | 单击元件单选；Ctrl 点击元件或引脚加选/取消；空白处拖框，完整包住元件本体即选中；Ctrl 拖框追加。 |
| 整组移动 / 删除 | 拖已选中的元件移动整组；Delete 删除整组及相连导线；各记一次历史。Esc 或失去捕获还原拖动。 |
| 封存子电路 | 选好元件→编辑→封存为子电路→输入名称；自动添加 `.json`，已有同名文件需确认覆盖。 |
| 子电路库 | 默认扫描启动工作目录的 `subcircuits/`；不存在时正常使用；保存后刷新，也可编辑→刷新子电路库。 |
| 放置子电路 | 点击“自定义子电路”下的条目→点击空白处；自动选中新块，可连续放；Esc 退出。 |
| 连线 | 引脚末端拖到目标引脚；非法连接在状态栏给出原因，Ctrl 点击引脚优先执行加选。 |
| 开关 / 属性 | 双击 SWITCH 拨动；多选时显示数量，单选显示只读属性。 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y；整块放置、移动、删除各一次；保留现有开关挡位，恢复删除元件时恢复其挡位。 |
| 平移 | 中键 / 滚轮 / Shift+滚轮；当前不支持缩放。 |
| 文件 | Ctrl+N/O/S/E：新建/打开/保存/导出；另存为在文件菜单。保存 JSON 与导出 `.net` 独立。 |

子电路是普通 `Schematic` JSON；仅保留选区内连线，网络从保留的导线重算。位置按 A 接口的**元件位置集合最小 x/y**归一化并对齐，不改几何契约。没有连到片段内其他元件的引脚自然作为对外引脚，不新增端口字段。

目前子电路只接受当前五类元件、兼容的引脚模板及零旋转；不兼容文件会跳过/拒绝，不静默丢弃连线。显式元件名称保留，默认 id 标签随新 id 更新。

开关挡位仍不写入 JSON，新建/打开归零；属性只读，真符号/旋转编辑/缩放/环路提示/主题仍未实现。保存需要保留的内容后再新建或打开，当前未提供未保存改动确认。

- 模型结构变化后重新 load 仿真并重放开关；网络只从 wires 推导，导出选区不带走外部导线。
- 历史上限50。只给设计编辑入栈，分支编辑清重做，拖动取消/拨开关不入栈。历史快照包含开关挡位以恢复被删开关；恢复时仍存在的开关优先使用当前挡位。
- `OnDocumentReplaced()` 默认用于新建/打开清挡位；历史恢复显式保留挡位。整组松手时提交按下前快照，捕获丢失或 Esc 还原所有成员。

- 子电路先在独立模型校验可展开性与连线数，拒绝重复 id、无效引脚/连线、未知类型和不兼容引脚；不修改 A 的实现。
