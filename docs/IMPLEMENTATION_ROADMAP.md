# 前端表现层与交互层 · 个人开发路线图

> 范围：仅模块 1（用户界面）与模块 3（绘图与编辑）。
> 模块 2（元件库）、模块 4（文件功能）、模块 5（电路仿真）由 core 层 / 其他同事负责，本路线图不涉及。
> 接口契约（阶段四使用）：core 层将交付 `Netlist`（网表数据）与 `ISimObserver`（仿真变化回调接口）。
