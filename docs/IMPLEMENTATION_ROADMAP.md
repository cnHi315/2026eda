## 阶段五:画布体验与性能(阶段四后补,来自 issue 1 / 4)

- [x] **画布滚动 / 平移**(issue 1)—— 中键拖动 + 滚轮 / Shift+滚轮;`m_origin` 即平移量,
      坐标换算仍只有 `ToScreen()` / `ToLogical()` 一处,网格锚定逻辑原点,平移后命中检测与拖拽照常
- [x] **局部重绘**(issue 4)—— 拖拽 / 橡皮筋 / 悬停只 `RefreshRect()` 受影响矩形,
      网格绘制按 `GetClippingBox()` 限定范围;元件查找加 id→指针索引缓存
- [x] **性能摸底** —— 400 个元件约 13.5 ms/帧、1000 个元件约 33 ms/帧(拖拽 + 重绘全流程)
