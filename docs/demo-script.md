## 一、正文脚本

> 格式：**操作** → 应该看到 → 「台词」 → ⚠️ 兜底

### 第 1 步 · 启动（15 秒）

**操作**：终端执行 `./build/CircuitEditor`

**应该看到**：标题 `Circuit Editor — 未命名`，左「元件库」（中文：与门/或门/非门/开关/LED）、中画布（网格）、右「元件属性」，状态栏右侧 `元件 0 | 导线 0 | 网络 0`

**「台词」**：
> 这是原理图编辑器的主界面，三栏布局：左边是元件库，中间是绘图区，右边是属性表。状态栏实时显示当前原理图的元件、导线、网络数量。

⚠️ **兜底**：起不来 → 检查是否在仓库根目录；仍不行就换预置的二进制或录屏。

---

### 第 2 步 · 放置元件（25 秒）

**操作**：点左侧「开关」→ 在画布左上点一下；再点一次画布放第二个开关；点「与门」→ 放；点「LED」→ 放；按 `Esc` 退出放置模式

**应该看到**：依次出现 `SW1`、`SW2`（左列）、`U1`（中间）、`LED1`（右侧）；位置自动吸附到 20 像素栅格；状态栏变成 `元件 4 | 导线 0 | 网络 0`

**「台词」**：
> 在元件库里选类型就进入放置模式，可以连续点、连续放，位置自动吸附到栅格。放完按 Esc 退出。

⚠️ **兜底**：
- 放歪了 → 不用重来，**直接左键拖动**到大致位置，松手自动吸附
- 颜色/名字看不清 → 继续，下一步连线会证明位置对

---

### 第 3 步 · 连线（30 秒，**最容易翻车的一步**）

**操作**：从 `SW1` 的引脚 `Y` 按下鼠标 → 拖到 `U1` 的引脚 `A` → 松开。同理：`SW2.Y → U1.B`、`U1.Y → LED1.A`

**应该看到**：拖动时出现虚线橡皮筋，靠近合法引脚会吸附并显示橙色小圆；松手后出现导线，状态栏报 `已连线 SW1#0 → U1#0  网络：net1`；三次之后 `元件 4 | 导线 3 | 网络 3`

**「台词」**：
> 连线的规则是"引脚到引脚"，靠近引脚会自动吸附。非法的连线——比如自己连自己、两个输出直连、或者重复连——会被拒绝，状态栏会给原因。

⚠️ **兜底**（按顺序试）：
1. 状态栏报了原因 → **照着念原因**，然后重新拖（这反而是加分项，能证明校验在工作）
2. 拖不动 / 没反应 → 确认已经按过 `Esc` 退出**放置模式**（放置模式下点击是"放元件"不是"连线"）
3. 引脚点不中 → 瞄准**引脚末端的小方块**，比元件框外面一点点
4. 彻底乱套 → `Ctrl+N` 新建重来，40 秒能重做一遍

---

### 第 4 步 · 仿真：拨开关（20 秒，**最能打的一部分**）

**操作**：在 `SW1` 上**双击**左键；再双击 `SW2`

**应该看到**：开关翻到 `1`（底色变化），导线变**亮绿**，`LED1` 亮起**橙色**；状态栏报 `开关 SW1 打开(1)`；计数**不变**（`元件 4 | 导线 3 | 网络 3`）

**「台词」**：
> 双击开关就是拨动它，信号沿着导线传播，导线按电平着色——高电平亮绿、低电平暗绿、未知灰色，LED 跟着亮起来。整个过程是事件驱动的，不用手动刷新。

⚠️ **兜底**：
- 双击没反应 → 确认**在元件框内**双击、且不在放置模式；单击只选中不拨动
- 线没变绿 → 检查那两个开关是不是都连到了 `U1` 的**输入**（`A` 和 `B`）

---

### 第 5 步 · 验证"与"逻辑（15 秒）

**操作**：再双击 `SW1` 关掉它

**应该看到**：该网络变**暗绿**，`LED1` **熄灭**；再双击打开 → 恢复点亮

**「台词」**：
> 与门要求两个输入都是 1 才输出 1。关掉一个开关，LED 就灭了——这正是真值表的行为。

---

### 第 6 步 · 选中 / 属性表 / 移动（20 秒）

**操作**：单击 `U1` → 看右侧；左右拖动一下 `U1`；点空白处取消选中

**应该看到**：`U1` 出现蓝色选中框；右侧属性表显示 `id=U1`、类型、名称、位置、旋转、**引脚表**（只读）；拖动时实时跟随，松手吸附栅格，挂在上面的导线跟着走

**「台词」**：
> 选中元件，右侧就能看到它的全部属性，包括引脚表。拖动会实时跟随，导线会自动跟着元件走。

⚠️ **兜底**：拖乱了 → `Ctrl+Z` 撤销（见下一步，正好串起来）

---

### 第 7 步 · 撤销 / 重做（15 秒）

**操作**：`Ctrl+Z` 撤销一次 → 再 `Ctrl+Y` 重做

**应该看到**：刚才的拖动被还原 → 再恢复；没有可撤销内容时，菜单「编辑」与工具栏的撤销/重做按钮**置灰**

**「台词」**：
> 撤销是快照式的：每次真正的编辑前把整份原理图压栈，所以撤销一定回到一致的状态。栈深 50 层。

> ⚠️ 注意口径：**撤销后开关会回到关闭**（v1 快照只含原理图，不含仿真状态，状态栏会提示），这是已知限制，可以主动说出来。

---

### 第 8 步 · 保存（20 秒，**T-12 的核对点**）

**操作**：`Ctrl+S` → 弹出保存对话框 → 文件名填 `demo.json` → 保存

**应该看到**：弹出**原生文件对话框**；保存后状态栏报已保存，标题里的文件名变成 `demo.json`

**「台词」**：
> 保存的是 JSON 格式的原理图，元件的 id、坐标、引脚、连线、网络全都在里面。

⚠️ **兜底**：
- 对话框没弹 → 说明已有保存路径，改用「文件 → 另存为」
- 目录不对 → 对话框里直接**输入绝对路径**

---

### 第 9 步 · 导出网表（15 秒，**T-12 的核对点**）

**操作**：`Ctrl+E` → 文件名 `demo.net` → 导出

**应该看到**：弹出对话框，导出后状态栏报 `已导出网表:...`；文件是 KiCad 的 s-expression 格式

**「台词」**：
> 导出的是标准网表，引脚按名字索引，可以直接导入 Pcbnew 走 PCB 设计流程 —— 这就是任务书里"导出标准网表"那条。

⚠️ **兜底**：状态栏报"原理图是空的" → 说明前面新建过，重新放置/打开 `demo.json` 再来

---

### 第 10 步 · 新建 + 打开（20 秒，**T-12 的核对点**）

**操作**：`Ctrl+N` 新建（画布清空）→ `Ctrl+O` 打开刚才的 `demo.json`

**应该看到**：元件、位置、连线**全部恢复**，计数回到 `元件 4 | 导线 3 | 网络 3`；**开关回到关闭态**

**「台词」**：
> 打开之后所有内容都恢复了。注意开关回到关闭 —— 因为开关状态属于仿真状态，v1 没有写进文件，这是刻意的（否则打开文件会直接带电，不好演示）。

## 二、兜底总表（现场速查）

| 现象 | 最可能的原因 | 立刻做什么 |
| --- | --- | --- |
| 点击画布只放元件，连不上线 | 还在**放置模式** | 按 `Esc`，再连 |
| 引脚点不中 | 鼠标在元件框内而非引脚末端 | 瞄准引脚末端的小方块 |
| 连线被拒绝 | 自环 / 输出直连 / 重复连线 | 照状态栏念出原因，换目标引脚（**这是功能，不是 bug**） |
| 双击开关没反应 | 单击了 / 不在元件上 | 瞄准元件框**双击** |
| LED 不亮 | 开关没连到 AND 输入 | 看导线是否连到 `U1.A` / `U1.B` |
| 保存/导出对话框没弹 | 已有保存路径 | 走「另存为」 |
| 画面卡住 | 误触了别的东西 | 等 3 秒；不行 `Ctrl+N` 重来 |
| 程序崩了 | 未知 | 换预置 `demo.json` 重开；有录屏就放录屏 |

## 三、可能被问到的问题（预备答案）

| 问题 | 回答 |
| --- | --- |
| 为什么元件是矩形？ | v1 统一"矩形 + 引脚名"，真符号（与门弧、非门圆圈、开关拨杆、LED 三角）排在 v1.1，几何参数由元件库模块提供 |
| 开关状态为什么不存？ | 仿真状态与设计数据分离：JSON 只存原理图，打开即"不带电"，避免打开文件就报错/误动作 |
| 组合环路怎么办？ | 目前仿真对环路只给未定义电平，D 已实现 `hasCombinationalLoop()` 检测，UI 侧的状态栏提示排在第 6 周候选 |
| 能缩放吗？ | 只支持平移（中键拖 / 滚轮 / Shift+滚轮），缩放预留了接口，排在候选 |
| 数据格式是什么？ | 自定义 JSON（version + components + wires + nets），网表导出是 KiCad s-expression |
| 怎么保证不丢数据？ | 撤销栈 50 层快照；保存走 JSON 往返，`io_test` 83 项覆盖（含"打开后继续编辑 id 不撞"） |
| 怎么测的？ | 四个单测目标（sim / model 57 / io 83 / integration 22）+ GUI 端到端脚本（MVP 9 项、阶段四 15 项、issue 1/4 11 项、撤销 16 项） |
