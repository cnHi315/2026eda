## 演示流程(MVP)

1. 启动软件,看到主窗口;
2. 从左侧元件库选择与门、开关 ×2、LED,点击画布放置;
3. 从开关引脚拖线到与门输入,从与门输出拖线到 LED;
4. 保存原理图(demo.json);
5. 导出网表;
6. 点仿真,拨动开关,观察 LED 亮灭。
