# 用户手册

> 演示 / 答辩时按这个流程操作,配合截图或录屏。

## 一、演示流程(完整链路,约 2 分钟)

1. **启动** —— 运行 `./build/CircuitEditor`(Windows 上是 `build\CircuitEditor.exe`),看到三栏窗口:左「元件库」、中画布、右「元件属性」,状态栏右侧显示 `元件 0 | 导线 0 | 网络 0`;
2. **放置元件** —— 在左侧点「开关」,再到画布空白处点一下 → 出现 `SW1`;同样再放一个开关(`SW2`)、一个「与门」(`U1`)、一个「LED」(`LED1`);放完按 `Esc` 退出放置模式(放置时自动吸附到 20 的栅格);
3. **连线** —— 从 `SW1` 的引脚 `Y` 按下鼠标,拖到 `U1` 的引脚 `A` 松开 → 出现导线,状态栏报 `已连线 SW1#0 → U1#0  网络:net1`;同样连 `SW2.Y → U1.B`、`U1.Y → LED1.A`;
4. **仿真** —— 在 `SW1` 上**双击**(左键) → 开关翻到 `1`,导线变亮绿、`LED1` 亮起橙色;再把 `SW2` 也双击打开 → 两个输入都是 1,LED 保持点亮;
5. **验证"与"的逻辑** —— 双击 `SW1` 关掉 → 该网络变暗、LED 熄灭;再双击打开 → 恢复点亮;
6. **保存与导出** —— 文件 → 保存(`Ctrl+S`)存成 `demo.json`;文件 → 导出网表(`Ctrl+E`)生成 KiCad 可导入的 `.net`;
7. **打开** —— 文件 → 新建清空画布;文件 → 打开选刚才的 `demo.json` → 元件、位置、连线全部恢复(开关回到关闭态,见"已知限制")。

## 二、操作说明

| 想做什么 | 怎么做 |
| --- | --- |
| 选择元件类型 | 左侧「元件库」点一项(显示名是中文:与门 / 或门 / 非门 / 开关 / LED);选中后进入**放置模式** |
| 放置元件 | 放置模式下点画布空白处;可连续放置;`Esc` 或点已有元件退出放置模式 |
| 选中元件 / 导线 | 左键单击(单击**不会**移动元件);点空白处取消选中 |
| 移动元件 | 左键拖动;实时跟随,松手吸附到 20 栅格;拖动中按 `Esc` 可还原位置 |
| 连线 | 从一个引脚按下 → 拖到另一个引脚 → 松开;拖动时虚线是橡皮筋,靠近合法引脚会吸附并显示橙色小圆;非法连线(自环 / 输出直连 / 重复连线)不会创建,状态栏给出原因 |
| 删除 | 选中元件或导线后按 `Delete`,或用菜单「编辑 → 删除选中」;删元件时挂在上面的导线一并删除 |
| 拨动开关 | 在「开关」上**双击**;状态栏报 `开关 SW1 打开(1)` / `关闭(0)` |
| 看元件属性 | 选中元件后,右侧「元件属性」显示 id / 类型 / 名称 / 位置 / 旋转 / 引脚表(**只读**) |
| 平移画布 | 中键拖动;或滚轮上下滚、`Shift`+滚轮左右滚(触摸板横扫也行);网格跟着一起走,松开后状态栏报原点偏移 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`,或菜单「编辑」、工具栏的撤销 / 重做按钮(没有可撤销内容时会置灰) |
| 新建 / 打开 / 保存 / 导出 | 菜单「文件」或工具栏按钮;保存是 JSON 原理图,导出是 KiCad `.net` 网表 |

## 三、快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+N` | 新建空白原理图(清空当前内容与撤销历史) |
| `Ctrl+O` | 打开 JSON 原理图 |
| `Ctrl+S` | 保存(没存过则弹出"另存为") |
| `Ctrl+E` | 导出 KiCad 网表(`.net`) |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Delete` | 删除选中的元件或导线 |
| `Esc` | 取消当前操作:退出放置模式 / 取消连线 / 取消拖动并还原位置 |
| 滚轮 / `Shift`+滚轮 / 中键拖动 | 平移画布(滚轮一格 = 一个 20 像素栅格) |
| `Ctrl+Q` | 退出程序 |

## 四、已知限制(v1)

1. **开关状态不进文件**:JSON 里不保存仿真状态,所以打开文件后所有开关回到"关闭";撤销 / 重做同理(状态栏会提示"开关回到关闭")。
2. **元件外观仍是矩形 + 引脚名**:与门弧线、非门输出圆圈、开关拨杆、LED 三角箭头等真符号排在 v1.1(需要元件库给出几何参数)。
3. **属性表只读**:暂时不能在属性表里改名字 / 坐标 / 旋转。
4. **画布不能缩放**:只支持平移;缩放预留了接口(`m_scale`),排在第 6 周候选。
5. **环路没有提示**:组合环路(例如把门的输出接回自己的输入)目前只会得到未定义电平,没有专门提示(由仿真模块负责)。
