# 需求与范围

> 状态:□草稿 ☑评审中 □稳定 | 负责人:A | 最后更新:2026-09-10(每次修改后更新这行)

## 任务分解

1. **任务1 硬件电路基础**:学习数字电路基础,理解逻辑电路设计基本原理。
2. **任务2 用户界面模块**:设计原理图编辑工具用户图形界面,提供工具栏、菜单以及快捷操作。
3. **任务3 元件库模块**:包含预定义电子元件,支持用户自定义元件。
4. **任务4 绘图与编辑模块**:元件放置、移动、连线等功能。
5. **任务5 文件功能模块**:设计并实现网表结构,支持设计文件的导入导出功能。导出标准网表文件,该文件能够被 PCB 软件加载,进行后续设计流程。
6. **任务6 电路仿真模块**:设计并实现动态电路信号传播与逻辑仿真。

## 最小演示目标(MVP)

打开软件 → 从元件库选两个开关、一个与门、一个 LED → 放置到画布 → 连线 → 保存 → 导出网表 → 仿真拨动开关,LED 正确亮灭。

这条链路跑通,项目就立住了。旋转、撤销/重做、时序电路都是加分项,有时间再做。
